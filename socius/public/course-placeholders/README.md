# Course Placeholder Images

This directory contains custom SVG placeholder images designed for the Arendelle Academy course catalog interface.

## Available Placeholders

- **banner-landscape.svg** - Wide banner image featuring majestic icy mountains and sun (1200x300)
- **emotional-intelligence.svg** - Heart icon with icy gradient background (400x225)
- **leadership.svg** - Crown icon with mountain backdrop and golden accents (400x225)
- **mindfulness.svg** - Lotus flower with ripple effects and soft colors (400x225)
- **communication.svg** - Speech bubbles with connection elements (400x225)
- **creativity.svg** - Lightbulb with sparkles and colorful paint splashes (400x225)
- **default.svg** - Snowflake design with icy theme (400x225)

## Design Theme

All images follow the Frozen/Arendelle Academy theme with:
- Icy blue and white color palettes
- Gradient backgrounds
- Soft glows and ethereal effects
- Professional, adult-oriented aesthetics
- Clean, modern iconography

## Usage

These SVG images are used throughout the CourseCatalog component as placeholders for:
- Course thumbnails
- Signature program images
- Mentor/Archetype profile images
- Banner images

## Benefits

- **Fast loading** - Vector graphics are lightweight
- **Scalable** - Look crisp at any resolution
- **Consistent** - Unified design language
- **No external dependencies** - No reliance on external image CDNs
- **Professional** - Custom-designed to match the application theme
