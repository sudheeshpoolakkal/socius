# Spiritus Frontend

This is the main frontend application for Spiritus, built with React and Vite.

## Technology Stack

- **React** - UI library
- **Vite** - Build tool and dev server with Hot Module Replacement (HMR)
- **ESLint** - Code linting

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Vite Plugins

This project uses the official Vite plugins for React:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) - Uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) - Uses [SWC](https://swc.rs/) for Fast Refresh

## Features

- Fast development experience with Vite HMR
- ESLint integration for code quality
- Optimized production builds
